# Lazio Primavera → SofaScore → ICS

Calendario sottoscrivibile della Lazio U20 / Primavera 1.

Fonte dati: SofaScore, team ID **826821**. La pagina ufficiale della squadra è:
https://www.sofascore.com/it/football/team/ss-lazio-u20-u20/826821

Il workflow GitHub Actions aggiorna il file `lazio-primavera.ics` ogni 6 ore e anche manualmente.

## URL per Google Calendar

https://raw.githubusercontent.com/robertoficerai9-prog/lazio-primavera-ics/main/lazio-primavera.ics

In Google Calendar: **Altri calendari → + → Da URL** e incolla l'URL qui sopra.

Nota: Google Calendar decide autonomamente la frequenza con cui ricarica i calendari sottoscritti; non è necessariamente ogni 6 ore.
